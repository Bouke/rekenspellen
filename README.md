# Rekenspellen

Oefenspellen voor breuken, tafels en plus/min, gehost via GitHub Pages:

- Breukenklimmer: https://boukehaarsma.nl/rekenspellen/breukenklimmer/
- Tafelsprint: https://boukehaarsma.nl/rekenspellen/tafelsprint/
- Sommenland: https://boukehaarsma.nl/rekenspellen/sommenland/
- Telfeest: https://boukehaarsma.nl/rekenspellen/telfeest/

Voortgang staat in de browser (localStorage) en kan in elk spel bewaard en hersteld worden via "Voortgang bewaren of herstellen".
